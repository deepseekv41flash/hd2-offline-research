## 3. 开测前你要做的（约 10 分钟，都在管理员 PowerShell 里）

把 zip 解压到一个**路径不含空格**的目录（例如 `C:\hd2-stage2\`），然后：

```powershell
cd C:\hd2-stage2

# ① 同步系统时间（必须；你的预检显示时钟没跟网络源同步）
w32tm /resync

# ② 接入（会自动做四件事：临时注释 Steam 屏蔽行、写 hosts 一行、装测试根证书、起本机 CRL 服务）

# ③ 自检 —— 全绿再开游戏
.\selfcheck.ps1 -ServerIp 106.52.201.42
```

`install-hosts.ps1` 需要**管理员** PowerShell（右键 PowerShell → 以管理员身份运行）。
它会明确打印每一件事的结果；看到「已临时注释 N 条 Steam 屏蔽行」「hosts 已写入」「CRL 服务已启动」即正常。

**关于你 hosts 里的 Steam 屏蔽行（重要，和上次的说明相反）**：
你机器上那 11 条 `127.0.0.1 <steam域名> #S302` 里包含 `login.steampowered.com`，
它指向本地会让 Steam 登录/联机失败。所以**这次允许脚本临时把它们注释掉**：
脚本只给这些行加前缀 `#HD2-STAGE2-DISABLED# `（原文件先备份），**不改行内容**；
结束跑 `rollback-all.ps1` 会原样恢复。你不需要手动改 hosts。

然后：
1. **启动 Steam 并确认已登录**（不要用「离线模式」）；
2. 正常从 Steam 启动一次游戏，确认 EAC 不弹错、能进主界面，进到主界面后先退出；
3. 等我这边说开始。

## 7. 常见问题

- **selfcheck 报 CRL 服务 FAIL** → 说明 `crl-server.ps1` 没起来；重新跑 `install-hosts.ps1`，或看 18081 是否被占用。
- **selfcheck 报时间未同步** → 再跑一次 `w32tm /resync`（管理员）；如果仍失败，告诉我，我改判定条件。
- **selfcheck 报 Steam 屏蔽行 count>0** → 说明注释没生效（多半没在管理员窗口跑）。
- **游戏报证书/连接错误** → 先 `rollback-all.ps1` 还原，再把 `collect-logs.ps1` 的 zip 给我；不要带着改过的环境反复试。
- **想中途退出** → 随时 `rollback-all.ps1`，不会留下改动。

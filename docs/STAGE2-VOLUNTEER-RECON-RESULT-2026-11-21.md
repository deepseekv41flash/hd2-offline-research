## 2. 唯一阻塞项与两条解法

### 2.1 首选：志愿者以管理员身份重跑一次 canary

`ConsentPromptBehaviorAdmin=0` 表示该机 UAC 对管理员账户是「不提示直接提权」。
只要志愿者的 Windows 账户属于 Administrators（家用机默认如此），
把测试包里的脚本**右键 → 以管理员身份运行**即可通过，不会有 UAC 弹窗打扰。

请志愿者回复两件事：
1. 以管理员身份重跑一次 canary（脚本会再测 hosts 写入）；
2. 贴一下账户类型判定命令的输出（任一即可）：
   - `whoami /groups | findstr /i "S-1-5-32-544"`（有输出 = 在管理员组）
   - 设置 → 账户 → 你的信息 → 账户类型（管理员 / 标准用户）

### 2.2 备选：不走 hosts，走「系统代理 + 用户级证书」（无需管理员）

若志愿者是**标准用户**（无法提权），还有一条非管理员路线：

- 用户级证书：已验证可写（canary ✓）；
- 系统代理：`HKCU\...\Internet Settings` 的 `ProxyEnable/ProxyServer` 是**当前用户可写**（无需管理员）；
- 我们已有可用的 CONNECT 代理（T6a 的 `tools/mitm_proxy.py`，支持把指定域名转发到本地 mock）。

**前提待验证**：游戏自称的官方 API（`api.live.prod.thehelldiversgame.com`）是否**走系统代理**。
T6a 只证明了 PlayFab/EOS/Sony 走系统代理（hosts 已把官方 API 截走，没走代理） → 我方需在本机做一次
「临时撤 hosts 行 + 设系统代理 + 启动游戏」的对照（约 15 分钟，需要一次管理员提权与启动游戏）。

> 判定：若成立，则阶段2 的接入方式可以从「hosts（要 admin）」切换为「系统代理（不要 admin）」，
> 志愿者门槛大幅降低；若不成立，则必须解决管理员权限。
